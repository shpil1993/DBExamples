## Що таке SQL Server?

* SQL Server — це система керування реляційними базами даних (RDBMS).
* Її розробляє і підтримує компанія Microsoft.
* Перша версія вийшла у 1989 році; сучасні версії — SQL Server 2019, 2022 та 2025.
* Працює на Windows і Linux, а також у контейнерах Docker.
* Існує хмарна версія — **Azure SQL Database**.
* Мова запитів SQL Server називається **T-SQL** (Transact-SQL).
* Є безкоштовні редакції: **Express** (для невеликих застосунків) та **Developer** (для розробки й тестування).

## Хто використовує SQL Server?

SQL Server широко використовують у корпоративному секторі: банки, страхові компанії, державні установи, інтернет-магазини, ERP- та CRM-системи. Він тісно інтегрований з екосистемою Microsoft: .NET, Power BI, Excel, Azure.

## Що таке SQL і T-SQL?

**SQL** (Structured Query Language — мова структурованих запитів) — стандартна мова для роботи з реляційними базами даних. За допомогою SQL можна:

* отримувати дані з бази даних;
* додавати, змінювати та видаляти записи;
* створювати бази даних, таблиці, представлення та індекси;
* налаштовувати права доступу.

**T-SQL** — це розширення стандартного SQL від Microsoft. Окрім звичайних команд SQL, T-SQL додає:

* змінні (`DECLARE @x INT`);
* керування потоком виконання (`IF...ELSE`, `WHILE`);
* обробку помилок (`TRY...CATCH`);
* збережені процедури, функції та тригери;
* багато вбудованих функцій.

## Редакції SQL Server

| Редакція | Призначення |
|---|---|
| **Enterprise** | Повний набір можливостей для великих систем |
| **Standard** | Основні можливості для середнього бізнесу |
| **Express** | Безкоштовна, з обмеженнями (розмір бази до 10 ГБ) |
| **Developer** | Безкоштовна, усі можливості Enterprise, але лише для розробки й тестування |

## SQL Server проти MySQL

Обидві системи використовують SQL, але мають відмінності в синтаксисі:

| Завдання | MySQL | SQL Server |
|---|---|---|
| Обмежити кількість рядків | `LIMIT 10` | `TOP (10)` або `OFFSET ... FETCH` |
| Автоінкремент | `AUTO_INCREMENT` | `IDENTITY(1,1)` |
| Об'єднати рядки | `CONCAT()` | `CONCAT()` або оператор `+` |
| Поточна дата й час | `NOW()` | `GETDATE()` / `SYSDATETIME()` |
| Замінити NULL | `IFNULL()` | `ISNULL()` |
| Екранування імен | `` `name` `` | `[name]` |

## Як починати?

У наступних розділах ми розглянемо, що таке реляційна база даних, як встановити SQL Server, і створимо навчальну базу даних для прикладів.
