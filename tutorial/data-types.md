Тип даних стовпця визначає, які значення він може зберігати: цілі числа, текст, дати, двійкові дані тощо.

Кожен стовпець, змінна, параметр і вираз у SQL Server має тип даних. Правильний вибір типу впливає на коректність даних, обсяг пам'яті та швидкість запитів.

## Рядкові (текстові) типи

| Тип | Опис | Максимальний розмір |
|---|---|---|
| `CHAR(n)` | Рядок **фіксованої** довжини, не-Unicode | 8 000 символів |
| `VARCHAR(n)` | Рядок **змінної** довжини, не-Unicode | 8 000 символів |
| `VARCHAR(MAX)` | Рядок змінної довжини, не-Unicode | 2 ГБ |
| `NCHAR(n)` | Рядок фіксованої довжини, **Unicode** | 4 000 символів |
| `NVARCHAR(n)` | Рядок змінної довжини, **Unicode** | 4 000 символів |
| `NVARCHAR(MAX)` | Рядок змінної довжини, Unicode | 2 ГБ |
| `TEXT`, `NTEXT` | Застарілі типи — використовуйте `VARCHAR(MAX)` / `NVARCHAR(MAX)` | 2 ГБ |

<div class="note" markdown="1">
**Який тип обрати для тексту?** Для текстів українською (і будь-якою мовою, крім англійської) використовуйте `NVARCHAR` — він зберігає символи Unicode. Літерали для таких стовпців пишіть з префіксом `N`: `N'Київ'`.

`CHAR(10)` завжди займає 10 символів (короткі значення доповнюються пробілами), а `VARCHAR(10)` — лише стільки, скільки фактично записано.
</div>

## Числові типи

### Цілі числа

| Тип | Розмір | Діапазон |
|---|---|---|
| `BIT` | 1 біт | 0, 1 або `NULL` (логічний тип) |
| `TINYINT` | 1 байт | від 0 до 255 |
| `SMALLINT` | 2 байти | від -32 768 до 32 767 |
| `INT` | 4 байти | від -2 147 483 648 до 2 147 483 647 |
| `BIGINT` | 8 байтів | від -9 223 372 036 854 775 808 до 9 223 372 036 854 775 807 |

### Точні десяткові числа

| Тип | Опис |
|---|---|
| `DECIMAL(p, s)` | Число з фіксованою точністю. `p` — загальна кількість цифр (1–38), `s` — кількість цифр після коми. Наприклад, `DECIMAL(10,2)` зберігає до 99 999 999,99 |
| `NUMERIC(p, s)` | Повний синонім `DECIMAL` |
| `MONEY` | Грошовий тип, 4 знаки після коми, ±922 337 203 685 477,5807 |
| `SMALLMONEY` | Грошовий тип, ±214 748,3647 |

### Наближені числа (з плаваючою комою)

| Тип | Опис |
|---|---|
| `FLOAT(n)` | Число з плаваючою комою; `FLOAT(53)` — подвійна точність (за замовчуванням) |
| `REAL` | Те саме, що `FLOAT(24)` — одинарна точність |

<div class="warn" markdown="1">
Для грошей і будь-яких значень, де важлива точність, використовуйте `DECIMAL`, а не `FLOAT`. Числа з плаваючою комою зберігаються наближено: `0.1 + 0.2` у `FLOAT` не дорівнює точно `0.3`.
</div>

## Дата й час

| Тип | Формат | Діапазон | Розмір |
|---|---|---|---|
| `DATE` | `YYYY-MM-DD` | 0001-01-01 … 9999-12-31 | 3 байти |
| `TIME(n)` | `hh:mm:ss[.nnnnnnn]` | 00:00:00 … 23:59:59.9999999 | 3–5 байтів |
| `DATETIME2(n)` | `YYYY-MM-DD hh:mm:ss[.nnnnnnn]` | 0001-01-01 … 9999-12-31 | 6–8 байтів |
| `DATETIMEOFFSET(n)` | `DATETIME2` + часовий пояс | 0001-01-01 … 9999-12-31 | 8–10 байтів |
| `DATETIME` | `YYYY-MM-DD hh:mm:ss[.nnn]` | 1753-01-01 … 9999-12-31 | 8 байтів |
| `SMALLDATETIME` | `YYYY-MM-DD hh:mm:ss` | 1900-01-01 … 2079-06-06 | 4 байти |

Детальніше — в уроці [Робота з датами](dates.html).

## Двійкові типи

| Тип | Опис | Максимальний розмір |
|---|---|---|
| `BINARY(n)` | Двійкові дані фіксованої довжини | 8 000 байтів |
| `VARBINARY(n)` | Двійкові дані змінної довжини | 8 000 байтів |
| `VARBINARY(MAX)` | Двійкові дані змінної довжини (файли, зображення) | 2 ГБ |
| `IMAGE` | Застарілий — використовуйте `VARBINARY(MAX)` | 2 ГБ |

## Інші типи

| Тип | Опис |
|---|---|
| `UNIQUEIDENTIFIER` | Глобальний унікальний ідентифікатор (GUID), наприклад `6F9619FF-8B86-D011-B42D-00C04FC964FF`. Генерується функцією `NEWID()` |
| `XML` | XML-документи та фрагменти (до 2 ГБ) |
| `JSON` | Нативний тип для JSON (Azure SQL та SQL Server 2025). У попередніх версіях JSON зберігають у `NVARCHAR(MAX)` |
| `SQL_VARIANT` | Може зберігати значення різних типів |
| `ROWVERSION` | Автоматично змінюване число-версія рядка (для контролю паралельних змін) |
| `HIERARCHYID` | Позиція в ієрархії (дерево) |
| `GEOMETRY`, `GEOGRAPHY` | Просторові дані: точки, лінії, полігони, координати на Землі |
| `CURSOR`, `TABLE` | Лише для змінних і параметрів |

## Перевірка типу та розміру

<div class="example" markdown="1">

```sql
SELECT SQL_VARIANT_PROPERTY(CAST(19.99 AS DECIMAL(10,2)), 'BaseType') AS BaseType,
       DATALENGTH(N'Київ') AS NVarcharBytes,
       DATALENGTH('Kyiv')  AS VarcharBytes;
```

## Перетворення типів

Для явного перетворення використовуйте `CAST` або `CONVERT`, а для безпечного — `TRY_CAST` / `TRY_CONVERT` (повертають `NULL` замість помилки):

<div class="example" markdown="1">

```sql
SELECT CAST('123' AS INT)              AS CastInt,
       CONVERT(DECIMAL(5,2), '3.14159') AS ConvertDecimal,
       TRY_CAST('abc' AS INT)          AS TryCastFails;
```
